# Icônes des modes d’action VTT

Ces six fichiers SVG reprennent les pictogrammes Lucide utilisés dans l’interface POPGG. Ils ont un fond transparent et peuvent être importés directement dans PowerPoint, Keynote, Google Slides ou Figma.

Correspondances :

- `preservation.svg` : Leaf
- `reconnexion.svg` : Link2
- `revitalisation.svg` : Sprout
- `regeneration.svg` : Building2
- `mise-en-reseau.svg` : Waypoints
- `circularite.svg` : Recycle

Source : Lucide, version 1.40.0, licence ISC. Les couleurs de trait correspondent à la palette sémantique actuelle de l’application.
