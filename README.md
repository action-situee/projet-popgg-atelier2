# POPGG atelier 2

Prototype du tableau de bord territorial du Grand Genève consacré au portefeuille d’indicateurs POPGG, à leurs rattachements VTT et à leur chaîne de responsabilité.

## Développement

```bash
pnpm install
pnpm dev
```

## Construction

```bash
pnpm build
```

Les hypothèses éditoriales, les sources de travail et les éléments restant à confirmer sont documentés dans `CONTENT_NOTES.md`.
